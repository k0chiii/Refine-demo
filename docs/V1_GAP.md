# v0 → v1 ギャップ一覧と対応状況

作成: 2026-10-10。v0（MVP: 校了までの単一経路）に対し、要件 v1.1 の F-01〜F-14・§2.2・§9 と突き合わせて「足りない機能」を洗い出し、v1 として追加した。制度承認待ち（D2/D3/D6）はポリシー値のままで、コードで業務規則を確定していない。

## v1 でも対象外（後続・承認待ち）

| 項目                                                           | 理由・次の一手                                                                                                    |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Slack 等への外部通知（F-11 の外部送信）                        | D8 未決。アプリ内通知の `notifications` テーブルを配信元にし、送信アクション＋失敗記録を追加する                  |
| 文章の版スナップショット・範囲指摘・notation 検査（F-12 / D7） | 後続。`Anchor` に `text_range` を追加する拡張点を確保                                                             |
| Nogiku Access 連動（登録・割当権限、グループ ACL）             | 拡張点（`orgPermissions`、`principalType = "group"`）のみ。Nogiku 側の権限名宣言と `/permission/check` 同期が必要 |
| AI による持越提案・OCR（D13）                                  | 人手の持越 UI が前提。提案は後続                                                                                  |
| 分割アップロード・大容量（D15）、負荷（A-13）、復元（A-14）    | 実測・運用手順が必要                                                                                              |
| 自己校了の独立確認者の定義（D2）、閲覧範囲の細則（D3）         | 制度承認待ち。ポリシー値のみ                                                                                      |
