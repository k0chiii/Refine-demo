## 2. 資料が定めていること

- 役割: 依頼者／制作者／校正者（誰でも可）／主管（統括）／校正担当（制作物ごと。MF100 は「専属は置かない」）／校了者（校了権限者）／回収者／当日代行の校了者。
- 段階: 体制づくり → 集約・登録 → 精査・仕様 → 第 0 版（ラフ）・第 1 版 → 版提出→校正（期限つき） → 反映判断→次版 → 校了 → 入稿・公開。「ラフ・初稿・再校」ではなく「第 0 版／第 n 版／校了／入稿」が委員会の語彙。
- 期限の目安: 校正期限は提出の 1〜3 日後。めいったーは 3〜4 日で 1 版、投稿 2 日前までに校了、第 1 版は 2 週間前。
- 校正の 4 種: 構造・デザイン・表記（基準は表記統一案）・情報（他制作物との齟齬・リンク・日付曜日）。「黒を白にするのが校正。グレーを白にするのは劣後」。
- 校了判断基準（MF96）: 正しい情報が過不足なく／正しい表記表現／制作目的に沿う／統一感／一般人が違和感を持たない。
- 提出時セルフチェック: デザイン指針（テーマカラー・フォント）、表記統一、「制作方針と見てほしいこと」をコメント、「前の版と見比べたか」「反映しなかった理由を明記したか」。
- must / must-not: 校正は誰でも入れてよいが反映は制作者が決める（理由と代案を添える）。校正期限前に次の版を出さない。期限前にコメントを解決しない。前版のコメントは消さない。校了権者が自作した場合は校了権者全員の合意。登録・情報修正は統括か制作物管理者が責任を持ち、情報修正は校了者の承認制。納期は余裕を持った日付で登録。表記統一の修正はサイレント修正可。緊急校正は専用ルートで「使わないことが前提」。回収は共同制作→部分回収→完全回収の段階で最終手段。

## 3. 照合

### (a) すでに沿っているもの

| 資料                                                                          | システム                                                                |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 第 0 版→第 1 版→第 n 版、各版に校正期限・変更点・見てほしい点・反映しない理由 | 版の kind rough/standard、changeSummary／focusNotes、採否と理由         |
| 反映は制作者が決め、理由を残す                                                | 採否 accepted／rejected／deferred                                       |

| 校了は校了権限者の明示宣言。自作の校了は合意                                  | 校了者の宣言・人数、制作者は校了者になれない、独立確認                  |

| 制作物ごとの Slack・Drive は作らない                                          | MF100 の方針と一致                                                      |

### (b) 沿っていない・足りないもの（重要な順）

1. 校正の 4 種（構造・デザイン・表記・情報）がコメントの種別に無い。「情報・表記は反映必須、他は制作者判断」を表せない。
2. 校正期限より前に次の版を出せる（資料は「期限前に版を更新しない」）。早い提出が議論を切る懸念。
3. 緊急校正のルート（発動できる人・優先して見てほしい／納期直前の区別）が未実装（D8 承認待ちのまま）。
4. 回収（共同制作→部分回収→完全回収、回収者≠校了者）が概念として無い。
5. 校正期限の既定値（提出の 1〜3 日後、めいったーは 3〜4 日／版、投稿 2 日前校了）が無く、毎回手入力。
6. めいったーの版更新条件（校正担当を含む 2 人以上のコメント）と、提出前セルフチェックの「前の版と見比べたか」「反映しなかった理由を書いたか」が無い。
7. 校了判断基準（5〜7 項目）のチェックリストが校了時に無い。
8. 校正担当の振り分け方針（種類別・担当別、「漏れなくダブりあり」）を確かめる手段が無い。
9. 入稿前チェック（CMYK・裁ち落とし 3mm・アウトライン化・PDF/X-4）と画像仕様（png・寸法・めいリソースの版）の検査が無い。
10. 対象範囲の例外（文書番号付き文書・企画対応制作物の別系統、当日期間の校了権委任）を表す区分が無い。
11. 登録情報の修正に校了者の承認が入っていない。
12. 校了権者が自作した場合の「全員合意」は、システムでは「制作者は校了者になれない」で問題自体を消している（制度上のずれ。利用者決定 2026-10-18）。

## 4. 提案（決めてほしいこと）

- 1・2・5・6 は実装の規模が小さく、資料との差が目に見える。順に PR にする案: 校正期限の既定値（提出＋3 日、SNS は＋3 日・投稿 2 日前） → 期限前の版提出を止める（統括だけ例外） → コメントに「校正の種類」（構造・デザイン・表記・情報）を付け、情報・表記は採否で「反映しない」を選べない → 提出前の確認に「前の版と見比べた」「反映しなかった理由を書いた」。
- 3・4（緊急校正・回収）は制度の決定が要る（D8）。
- 呼び方は「校了目標日」「専門確認」「受付期限」を資料の語に寄せるか決めてほしい。
