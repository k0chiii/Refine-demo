# 画面一覧（デモモードの撮影経路）

`apps/web` の**デモモード**（`pnpm build:demo` → `vp preview --mode demo`、バックエンド無しで Convex の実関数を `convex-test` によりブラウザ内実行）で、Nogiku モック委員 5 名を切り替えながら「登録済み制作物 → 版提出（専門確認の宣言） → 割当 → 指摘 → 専門確認完了 → 採否 → 第2版提出と指摘の持越 → 版比較 → 校了 → 通知」を一周する（v1 機能を含む）。撮影スクリプト: `apps/web/e2e/screenshots.mjs`（`pnpm screenshots`）。

**画像はリポジトリに置かない**（利用者決定 2026-10-14）。撮影すると `apps/web/e2e/out/screenshots/` に PNG が出る（git 管理外）。表の「撮影名」はそのファイル名。

画面構成は 2026-10-13 の見直し（[`UI_M3E.md`](UI_M3E.md) §11）を、2026-10-19 に入口を仕事で分けた（§83）: **制作／校正／制作物／FB** の 4 つの行き先＋管理。ホームは無く、制作（自分が作るもの）と校正（自分が確かめるもの）がそれぞれのホーム（色は青 1 つ。§88）。表記ルール・管理はアカウントのメニュー（広い画面はレールの下にも）。書くのは制作の FAB「作る」（版を提出／新しく書く）から。通知はアプリバーのアカウントの隣のベル（compact でも同じ位置。押すと全画面の通知シート）。制作物に関する操作はすべてエディタの引き出し（コメント／版／情報）で行う。エディタの見出し・戻る・校正を完了は共通アプリバーに入り、引き出しの開閉は紙面右端の縦ツールバー（§17）。サイドバーとレイアウトは M3 のウィンドウサイズクラス（§12）: 600 以上はレール（メニュー・FAB「作る」・行き先。折りたたみ時はアイコンのみ。FAB は版を提出できる制作物がある人だけ。§36）、599 以下はアプリバー（見出し＋アカウント）＋下部バー。制作・校正・制作物・管理の見出しもアプリバーに入る（§18）。検索バーは 2026-10-14 に一旦外した。compact のエディタ（制作物を開いた画面）は下部バーを隠し、共通アプリバーにはベルとアバターを出さない（§35 L-14）。引き出しはツールバーの「コメント・版・情報」で開くボトムシート（§30）。制作物を開いた画面の medium・expanded はレールを隠す（§35 L-13）。
