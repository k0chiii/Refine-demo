## 既知の制約・注意

- Convex の `_generated` はコミットしている。関数モジュールを追加・削除したら `pnpm codegen`（または `npx convex dev`）を実行する。
- ユーザー指定（制作者・校了者・校正者・ACL・担当者）は `UserPicker`（`users.search`）で選ぶ。候補は一度でもログインした Nogiku ユーザー。
- `apps/web` の `routeTree.gen.ts` はビルド時に生成（gitignore）。
- `vp check` は 0 エラー。警告は `void` 明示で解消済み。
- 本リポジトリから外部（Nogiku・Slack・LLM）へ実データを送る処理は無い。
